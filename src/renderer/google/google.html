🔗 Connect Google

Your Tama can read your calendar and mail, write emails (sent only after you confirm the whole draft), and create Docs & Sheets in a "Tama Drafts" folder. Everything runs on this PC with your own Google app, so no one else ever sees your data.

One-time setup (about 5 minutes)

  1. Create a Google Cloud project. Open ↗
    Name it anything, e.g. "Tama".
  2. Turn on the APIs (Gmail, Calendar, Drive, Docs, Sheets) for that project. Enable all ↗
  3. Set up the consent screen: Google Auth Platform → Branding/Audience: user type External, app name "Tama", your email. Then on Audience press Publish app (In production), otherwise Google logs you out every 7 days. Open ↗
  4. Create a client: Clients → Create client → Application type Desktop app → Create. Copy the client ID and secret. Open ↗
  5. Paste them here and sign in. Google will say "Google hasn't verified this app": that's expected for your own app. Click Advanced → Go to Tama.

Connected ✨

Try it in the terminal (Ctrl+Alt+K)

  • "what's on my calendar this week?"
  • "draft a reply to the latest email from my landlord"
  • "make a Google Sheet to track my gym sessions with a weekly total"
